# AEMEATH Studio v1.0.0

免費、非官方的 AEMEATH KA-LH-E-26001 鍵盤控制工具，透過本機網頁介面管理燈效、按鍵與宏。

## 主要用途

- **燈效與校色**：分組即時燈效、鍵盤內建燈效、一般／心型區校色、燈效方案保存及群組匯入匯出。
- **按鍵設定**：一般層與官方 Fn 功能、高級鍵 SOCD／MT／TGL／CB／END、單鍵還原。
- **宏編輯**：即時顯示錄製動作，插入鍵盤／滑鼠按鍵與延遲，拖曳排序及選擇播放模式。
- **備份與診斷**：寫入前備份、寫入後讀回驗證、備份還原、本機日誌與操作確認紀錄。
- **介面與啟動**：主題、系統匣背景執行、同版本重用與版本選擇；跨資料夾辨識需執行中版本也支援識別介面，無法驗證時不強制關閉程序。

## 使用方式

1. 下載附件 **AEMEATH-Studio-v1.0.0.zip**，完整解壓縮到可寫入的資料夾。
2. 使用 Windows 10／11，安裝 Python 3.11 或更新版本。
3. 雙擊 `Launch.pyw`，閱讀聲明後操作。詳細說明見包內 `README.md` 與 `先讀我.txt`。

支援目標鍵盤的 USB／2.4G 控制；不支援藍牙。本包不是獨立 EXE。

下載包不含開發者設定、日誌、備份、測試、`CHANGELOG.md` 或 `檔案用途.md`；使用聲明與字型授權保留。GitHub 自動附上的 Source code 為完整原始碼，不等同使用者程式包。
