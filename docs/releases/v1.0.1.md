# AEMEATH Studio v1.0.1

環境相容與啟動診斷修正版。

- 啟動前檢查 Python 版本、必要檔案、tkinter 與 data 寫入能力。
- 日誌或 tkinter 無法使用時，仍嘗試用 Windows 原生視窗顯示錯誤。
- 辨識 Python 重裝後的失效啟動路徑及 Windows 停用的啟動項目，在偏好設定顯示原因。
- 區分 Windows 拒絕本機連接埠與程序占用。
- 新增「環境與故障排除.md」，說明新版 Python 管理器、資料夾權限與自啟動修復。

下載 AEMEATH-Studio-v1.0.1.zip，完整解壓縮後執行 Launch.pyw。需要 Windows 10／11 與 Python 3.11 以上；不是獨立 EXE。不含私人設定、日誌、備份及開發文件，保留使用聲明與授權。

更新前結束舊版並備份 data；若改用新資料夾，重新啟用開機啟動以更新路徑。自動測試不等於所有電腦或鍵盤均已實機驗證；免費、非官方，不保證對硬體無損害，請先閱讀使用聲明。
