# 愛彌斯・絨雪輕歌 AEMEATH Studio

**v1.0.0** · 免費、非官方的 AEMEATH KA-LH-E-26001 鍵盤控制工具。

在本機瀏覽器介面調整燈效、按鍵與宏。即時燈效需要程式持續執行；內建燈效與按鍵設定會寫入鍵盤。

## 開發自述

覺得官方沒有提供訂製驅動實在有點可惜，所以腦子一抽，就決定嘗試自己做一個鍵盤燈效驅動。

整個專案全程使用 ChatGPT 協助製作，從 HID 通訊協定研究、功能設計到程式碼撰寫，基本上都是由 ChatGPT 完成，而我主要負責提出需求、測試功能以及回報問題。

原本只是想讓鍵盤的燈效有更多自訂空間，但想說做都做了，不如連按鍵設定也一起加進來。於是原本單純的燈效驅動，就這樣逐漸變成了一個功能越來越多的鍵盤驅動。

開發途中其實一直在猶豫要不要公開，畢竟我無法保證這個驅動完全沒有問題，也不能確定它是否有可能對硬體造成損害。最後還是決定公開出來，讓有需要的漂泊者可以自行嘗試使用。

至於後續會不會繼續更新或添加新功能，我也不確定。畢竟一開始真的只是腦子一抽才跑來做這個，完全沒想到最後會搞成這樣。

## 下載與啟動

1. 到 [Releases](https://github.com/minato-akira/AEMEATH-Studio/releases/latest) 下載 **`AEMEATH-Studio-v1.0.0.zip`**。
2. 使用 Windows 10／11，安裝 Python 3.11 或更新版本。
3. 完整解壓縮到可寫入的資料夾，雙擊 **`Launch.pyw`**。
4. 閱讀操作風險與資料說明，連接鍵盤後開始設定。

請選擇上述程式 ZIP；GitHub 自動提供的 `Source code` 是開發原始碼，包含測試與開發文件。此版本不是獨立 EXE，仍需要 Python。

## 可以做什麼

| 功能 | 用途 |
|---|---|
| 即時燈效 | 分組選鍵，設定恆亮、呼吸、心跳、波浪、彩虹及觸鍵效果，調整亮度與速度。 |
| 內建燈效 | 套用鍵盤官方內建效果與支援的參數；套用後停止持續傳送燈效。 |
| 校色與方案 | 調整一般按鍵／心型區顏色，保存燈效方案，匯入或匯出燈效群組。 |
| 按鍵設定 | 點選鍵盤預覽設定功能；Fn 層提供官方特殊功能與單鍵還原。 |
| 高級鍵 | 設定 SOCD、輕觸／長按 MT、切換 TGL、組合鍵 CB、按下／放開 END。 |
| 宏編輯 | 錄製或插入鍵盤、滑鼠按鍵與延遲，拖曳排序，設定播放模式。 |
| 備份還原 | 裝置寫入前保留備份，寫入後讀回核對；從介面選擇備份還原。 |
| 偏好與背景執行 | 切換主題、設定開機啟動與系統匣背景執行。 |

首次使用預設為星海主題，搭配底色、WASD 呼吸、功能鍵彩虹與心型核心。既有設定不會因更新而自動改成預設。

## 支援與注意事項

- 目標裝置：**AEMEATH KA-LH-E-26001**；USB／2.4G 功能依鍵盤與接收器而異，**不支援藍牙**。
- 寫入前請保存設定並關閉其他鍵盤控制工具，寫入時勿拔除裝置；宏請先在安全情境測試。
- 不保證所有環境相容，也不保證使用本工具不會對硬體造成損害。正式版仍可能有錯誤，備份不保證完整恢復。
- 本工具與庫洛及鍵盤製造商無隸屬或背書關係，不能取代官方支援。

使用前請閱讀 [使用聲明](使用聲明.md)，程式內「關於與聲明」也提供說明。聲明變更後會要求重新確認。

## 資料與問題回報

設定、備份、日誌與聲明確認紀錄保存在程式旁的 **`data/`**；自選背景圖片存於瀏覽器，匯出檔依瀏覽器下載位置保存。程式不會自動上傳這些資料。

遇到問題可到 [GitHub Issues](https://github.com/minato-akira/AEMEATH-Studio/issues) 回報操作步驟、版本與連線方式，並附上 `data/logs/` 中必要的日誌片段。**分享前請移除個人及機密資料，不要上傳整包 data。** 回報不保證回覆、修復或持續維護。

無法啟動時，可在程式資料夾開啟 PowerShell，執行 `py -3 .\Launch.pyw`；查看 `data/logs/studio.log`，或啟動記錄器失敗時的 `data/logs/launch-error.txt`。
