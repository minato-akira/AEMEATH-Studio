## v0.6.1 亮度修正與診斷

本次僅處理內建燈效亮度流程，其他介面改版待辦未納入。

- 套用前固定參數，操作中暫停編輯，避免畫面數值與送出內容不一致。
- 亮度滑桿明確顯示目前選擇的 1～5 檔；成功訊息顯示讀回驗證的檔位。
- 每次套用僅送一次 0x23，之後等待並最多重讀四次 0x13，處理設定載入時序；不自動重寫。
- 讀回核對 v1.26 實際組裝的欄位，不再把保留欄位當成設定鏡像。
- 仍不符時列出各欄位的要求／實際值，可按「下載亮度診斷記錄」。包含原始讀取、送出資料、ACK、每次讀回及差異。未通過驗證不保存為成功套用。
- 診斷記錄保存在使用者設定目錄的 lighting-backups；latest-native.json 是最近操作，其他獨立檔保留歷史。

39 項單元測試通過。瀏覽器模擬測試確認亮度 1／3／5 從滑桿到 API、封包及讀回的完整流程。另驗證延遲讀回及亮度固定在 5 的失敗案例，均只寫一次。

**目前缺少 v0.6 失敗當次的實機原始回覆，因此原始問題是否由時序造成尚未確認，不能保證本版已排除實機亮度不變的原因。** 如果再次失敗，請提供新診斷檔，不用反覆套用或重新錄製所有燈效。

## v0.6 使用方式

完整解壓，結束舊版後執行 Launch.pyw。會沿用舊設定並遷移至 v6，關閉失效的 hardware_master 設定。

- 首頁可切換休閒與低延遲模式。切換會停止即時燈光；休閒按開始共鳴，低延遲選內建效果後按套用。
- 休閒亮度透過 RGB 計算；不再讀寫原廠亮度。實機已回報原廠亮度不影響這條路徑。
- 低延遲提供官方模式 1～19 及關燈，依模式提供顏色、速度、方向等參數。每次套用前備份、寫入後讀回。完成即關閉 HID 控制連線，不持續傳送燈效。名稱表示減少燈效通訊，並非已測得遊戲延遲降低。
- 原廠設定索引 4 固定寫 FF、末尾 AA55；讀回不比較這些寫入專用欄位。保留其他原始欄位，不寫入韌體。備份位於使用者設定目錄 lighting-backups。
- 燈效方案可保存完整休閒群組與整體亮度，或一套內建效果參數。兩模式各最多 30 個；校色為全域／心型設定，不隨方案切換。
- 首頁顏色校準分頁有 11 步人工引導：白、RGB、混色及低亮測試。用偏色修正與數值輸入自行調整，按儲存校色保留。沒有測色感測器，不能自動判斷實際色偏。低延遲模式不能進行串流試色，請先切至休閒。
- 資料流採不同相位的垂直光流，不依左右次序啟動。心跳有完全熄滅區間，不使用背景色；其他適用效果可設定背景顏色／亮度。
- gamma 最低 0.15、心跳最低 15 BPM 保留。逐鍵亮度仍須轉換 RGB，暗部仍受 USB／RGB565 量化限制。

## 驗證界線

軟體測試及模擬裝置讀寫通過不等於實機成功。USB／2.4G 原廠模式切換、新資料流觀感及校色結果仍需使用者試用。低延遲模式只提供單一內建效果，不支援多個不同內建動畫按區域同時播放。

## 先開始：本版不再使用 .bat，也不需要安裝套件

1. 完全結束所有舊版（包含系統匣），並關閉官方鍵盤網頁驅動。
2. 如果電腦尚無 Python，安裝 https://www.python.org/downloads/windows/ 的 Python 3.11 以上；也可使用 Microsoft Store 的 Python。使用官方簽署的安裝版本，保留 Python Launcher。
3. **完整解壓 ZIP** 到固定、可寫入的資料夾。不要在 ZIP 預覽中執行。
4. 雙擊 **Launch.pyw**。程式會開啟本機瀏覽器介面。
5. 若雙擊沒反應，在此資料夾的檔案總管路徑列輸入 `powershell`，執行：

```powershell
py -3 .\Launch.pyw
```

本版沒有 Install.bat／Start.bat，不需要 `pip install`，也不需要前一版的 .venv。請勿再使用舊版啟動腳本。

手動以 PowerShell 啟動時請先保留終端機視窗；若安裝了無視窗 Python Launcher，也可用 `pyw -3 .\Launch.pyw` 啟動。

預覽方式：雙擊 web/index.html 只看靜態介面（部分瀏覽器會限制本機字型）；完整動態預覽可執行 `py -3 .\Launch.pyw --preview`，此模式不開啟 HID。實機使用不要帶 --preview。

## 智慧型應用程式控制（SAC）封鎖的處理

上一版的下載 .bat，或其中某個原生 Python 套件，可能成為封鎖來源。沒有看到你的封鎖檔名，不能確定是哪一項。

本版從程式交付方式處理：

- 移除下載的 .bat／PowerShell 啟動腳本與第三方 HID 原生擴充。
- 沒有未簽署的 PyInstaller EXE，不會下載額外 DLL。
- 直接由官方 Python 執行原始碼，HID 與系統匣使用 Windows 內建系統 API。
- 圖形介面由你現有的瀏覽器呈現，不另外安裝 WebView 或 GUI 套件。

這能移除上一版的幾個常見封鎖來源，**不保證 SAC 一定放行，也不是替程式添加受信任數位簽章**。目前 Microsoft 不提供讓使用者替單一應用程式加入 SAC 例外的功能。解除下載標記不等於解除 SAC。

若仍被擋：

1. 記下被封鎖的完整檔名／路徑。如果是 python.exe、pythonw.exe 或 Python 本身的 DLL，先確認安裝來源；不要沿用不明來源的便攜 Python。
2. 若介面能開啟，進入「啟動協助 → 讀取啟動診斷」。這會唯讀列出 Python 路徑及最近兩天 Code Integrity 3077／3033 事件；沒有足夠權限或沒有事件時會顯示原因。資訊只在本機顯示，不上傳。
3. 若連介面都不能開，請提供 Windows 封鎖畫面與檔名。不要把系統安全設定是否關閉，當作已解決程式相容性的證據。

程式不會改防毒、SAC、ExecutionPolicy 或群組原則。若將來需要可直接散發且能在 SAC 下穩定安裝的 EXE，仍需發行者憑證簽署或正式的商店發行；自簽不能假裝成受信任的發行者。

## 光效、選區與心跳

- 光效群組從左到右疊加，右側優先。可新增、刪除、前後排序。
- 支援恆亮、呼吸、彩虹、波浪、閃爍、心跳、核心資料流、觸鍵星光、星光漣漪、熄滅。
- 各組獨立顏色、亮度、速度；心跳獨立 15～180 BPM。
- 心跳的 BPM 指每分鐘「主拍＋次拍＋舒張」的完整週期；高 BPM 受實際傳輸更新率限制。
- 預覽即時改變；按「套用並儲存」才更新實機與磁碟上的設定。
- 滑鼠點選／拖曳選區；切換群組不丟棄編輯。「互動試彈」可點按鍵或直接敲實體鍵盤測試。
- 在「實物對照」中，可將選區疊在官方商品正面圖上核對。

心型預設依官方商品圖的 **20 顆藍色半透明鍵帽**：

- 上排：8、9、-、=（ID 24、25、27、28）
- 第二排：U、I、O、P、[、]（ID 39～44）
- 第三排：J、K、L、;、'（ID 55～59）
- 第四排：M、,、.、/（ID 71～74）
- 最下方：右 Alt（ID 84）

點「♡ 藍色心型」可還原此預設。鍵位資料來自官方配置，寬鍵、錯列、數字區起始排與箭頭區依商品圖比例排列。不是測量實體成品所得，仍可用實物對照校正。

「辨識選區」暫時只亮目前選區冰藍色，其他按鍵熄滅；再次點擊恢復。實機辨識須先開始共鳴。停止輸出不會主動改寫鍵盤原廠模式，可能停留最後畫面；用鍵盤原有快捷鍵或官方驅動切回內建效果。

## 2.4G 支援範圍

「偏好設定 → 連線偏好」可選自動、USB、2.4G。自動優先 USB；切換後請停止並重新開始。

- USB：0C45:271B、FF68/97、64-byte，0x32，沿用使用者實際擷取確認的通道。
- 2.4G：0C45:FEFC、FF80/1、32-byte，0x35，RGB565 big endian，7 包／90 鍵畫面。
- lightingVersion=1 的 FF70/113 64-byte 分支使用 0x3C；只有實際版本匹配才啟用，不套用於你回報的版本 0。
- 藍牙不支援。

**2.4G 封包已與官方前端演算法逐 byte 比對，但尚未在你的接收器實測。** 不能把「寫入完成」當成鍵盤必然顯示成功。本版記錄送出與回覆計數，方便首次驗證；legacy 音效路徑依官方採短回覆等待，不強制每包都有 ACK。2.4G 上限 12 FPS，USB 可選 5～20 FPS，實際依傳輸與裝置回覆調整。

動畫幀使用即時 0x32／0x35／0x3C，不使用持久化 0x24 或動畫 0x42。低延遲模式套用時另外使用 0x13 讀取、0x23 保存原廠燈效；休閒模式不寫入原廠亮度。「按鍵設置」頁另使用已分析的 0x11／0x12／0x15／0x16 查詢，以及 0x21／0x22／0x25／0x26 原廠設定寫入；不含 OTA、改韌體或任意位址存取。

## 偏好設定與背景功能

- 登入 Windows 時啟動：只設定目前使用者的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\AEMEATHResonanceStudio` 單一值，關閉開關即移除，不需管理員。
- 啟動時留在背景：只影響登入啟動；若系統匣建立失敗，會開啟網頁保留操作入口。
- 自動開始燈光：登入啟動後使用已保存的群組；手動啟動仍由你按開始。
- 斷線重連：每 3 秒重新查詢已知介面並恢復即時燈光。預設關閉。
- 整體亮度、更新率、晨霧／星海／像素主題、減少裝飾動畫。
- 背景按鍵互動：預設關閉。開啟後，僅透過 Windows GetAsyncKeyState 讀取按下狀態，把燈號與時間暫存在記憶體 2 秒，**不保存文字、不讀剪貼簿、不上傳**。會回應所有連接到電腦的鍵盤，不能只辨識 AEMEATH。Fn 不會提供可獨立辨識的 Windows 按鍵事件。
- 未開啟背景按鍵互動時，只回應本機介面內的按鍵試彈。
- 背景圖片僅保存於目前瀏覽器，限制 PNG／JPEG／WebP 2.5 MB；請自行選擇有權使用的圖片。
- 匯出／匯入群組設定；匯入不會偷偷開啟登入啟動或背景按鍵功能。

關閉瀏覽器分頁後，Python 仍在背景運作；Windows 系統匣雙擊可開啟，右鍵可停止／結束。也可再次雙擊 Launch.pyw 打開同一個實例。結束請使用首頁的「結束應用」或系統匣選單。

請在啟用登入啟動前，先把程式放到固定位置；移動後應先關閉再重新啟用該開關。若 Windows 工作管理員停用了這個啟動項目，也需要在工作管理員重新啟用。

## 資料與隱私

設定、啟動資訊、輪替錯誤記錄位於 `%LOCALAPPDATA%\AEMEATH_Background\`。除你主動點擊錄製宏所建立的動作外，不保存日常按鍵，不啟用追蹤或遙測。背景主程式只監聽 127.0.0.1:47635，具有每次啟動隨機 token、Host／Origin 檢查與命令白名單；不是對外網頁服務。

只開啟已知 AEMEATH 廠商與控制介面，不替換系統驅動，不開啟一般鍵盤輸入 HID 介面。全域按鍵反應是可關閉的獨立功能。

本機字型為 Noto CJK TC 子集，重新命名為 Snowlight Sans TC／Snowlight Serif TC；UI 無須連網載入字型。完整授權在 web/fonts/LICENSE.txt。
