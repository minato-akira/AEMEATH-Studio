# 愛彌斯・絨雪輕歌 鍵盤控制台 v0.6.3.6（測試第 6 版）

版本號前三段表示正式版本；開發測試版會加上第四段序號，正式版省略第四段。

供 AEMEATH KA-LH-E-26001 使用的非官方鍵盤控制工具，可調整按鍵、宏與燈效；不能取代鍵盤官方驅動。

## 使用前請閱讀

本工具免費、非官方，不保證所有環境相容。裝置寫入可能改變或遺失設定；請先備份，避免其他驅動同時控制同一裝置。宏請先在安全情境測試。

完整支援範圍、操作風險、資料處理、責任限制與法定權利保留，見 [使用聲明與資料處理說明](使用聲明.md)，程式內「關於與聲明」亦提供全文。聲明不能排除法律規定不得免除的責任。

## 開始使用

1. 使用 Windows 10／11，並準備 Python 3.11 或更新版本。
2. 將整個程式資料夾解壓到可寫入的位置。
3. 執行 `Launch.pyw`，在開啟的瀏覽器頁面操作。

程式會檢查已執行的版本：同版本會開啟現有程式；版本不同時會詢問要保留哪個版本。使用鍵盤設定時，依畫面提示連接鍵盤。

## 主要功能

- **鍵盤設定：** 編輯一般層與 Fn 層；Fn 層提供鍵盤官方功能。支援高級鍵與宏設定，並可查看、備份及還原設定。
- **燈效：** 使用休閒燈效或鍵盤內建燈效，調整顏色、亮度、速度與鍵位選區。
- **偏好設定：** 調整介面與背景操作選項。

裝置操作前會要求確認使用聲明；聲明變更後重新確認。確認及操作紀錄保存在 `data/logs/audit`，包含聲明副本、雜湊、版本、時間與結果。紀錄不會自動上傳，也不能作為不可竄改或身分驗證的證明。

## 問題回報

回報僅供參考，不保證回覆、修復、採納或持續維護，也不承諾處理時程。

設定、鍵盤備份、燈效備份、執行狀態與日誌主要保存在程式資料夾的 `data`；背景圖片另存在瀏覽器本機儲存空間，匯出檔案依瀏覽器的下載設定保存。首次啟動會從舊位置遷移資料，並在新版本成功啟動後清理已確認複製完成的舊檔。遇到錯誤或功能無反應時，請先遮蔽個人及機密資料，再提供 `data\logs` 中必要的日誌片段，並簡述操作步驟與連線方式，方便重現問題。日誌可能包含裝置及操作診斷資料，分享前請先確認內容。

若程式無法啟動，先確認已完整解壓縮程式資料夾，並安裝 Python 3.11 或更新版本。可在程式資料夾開啟 PowerShell，執行 `py -3 .\Launch.pyw` 查看啟動訊息；錯誤記錄位於 `data\logs\studio.log`，若啟動記錄器本身失敗則查看 `data\logs\launch-error.txt`。

鍵盤設定中的備份與還原可用來保存或恢復按鍵設定。燈效方案可在程式介面中匯出與匯入。

## 支援範圍

本工具面向 AEMEATH KA-LH-E-26001。USB 與 2.4G 的支援依鍵盤及接收器而定；藍牙連線不支援。實際結果仍以你的鍵盤與連線狀態為準。

本專案由使用者社群維護，與庫洛或鍵盤製造商無隸屬關係。遇到裝置異常時，請先停止操作並使用官方驅動恢復設定。
