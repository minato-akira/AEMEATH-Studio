START HERE

新的啟動方式

  1. 安裝來自 python.org 或 Microsoft Store 的 Python 3.11 以上。
  2. 完整解壓縮程式，雙擊 Launch.pyw。
  3. 若無法雙擊，在此資料夾開啟 PowerShell，執行：py -3 .\Launch.pyw
  4. 關閉官方網頁驅動，選擇 USB 或 2.4G，再開始共鳴。

瀏覽器只顯示本機介面，背景燈光由 Python 獨立執行，關閉網頁不影響輸出。

WINDOWS SECURITY

智慧型應用程式控制

新版移除了下載的 .bat、第三方原生 HID 套件與未簽署的打包 EXE，直接使用 Python 與 Windows 系統 HID API。

這是減少封鎖來源的相容方式，不能保證 Windows 一定放行。若連 Python 自身也被擋，需確認安裝來源與封鎖檔名。

目前 Windows 沒有替單一應用程式加入 SAC 例外的功能。「解除封鎖」下載標記也不等於可略過 SAC。程式不會修改你的安全設定。

僅在你點擊後讀取 Python 版本及近期 Windows Code Integrity 封鎖事件，顯示於本機，不上傳。

KNOW YOUR KEYBOARD
藍色心型與 2.4G
心型預設依官方商品正面圖標出 20 顆半透明鍵帽。實物對照可核對位置；也能自行調整選區。
USB 沿用音效擷取確認的 0x32 即時通道。2.4G 依官方網頁的 32-byte / 0x35 / RGB565 路徑實作；本地尚無實體接收器，需你的首次實測。
若出現「未回覆」，先確認鍵盤已喚醒、接收器連接正常，並關閉其他控制程式。
